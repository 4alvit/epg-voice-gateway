# Governance and continuity

The project is maintained by GitHub user 4alvit. The maintainer is responsible for technical direction, reviewing contributions, security intake and release/deployment acceptance. Proposals and decisions belong in public GitHub issues or pull requests unless they contain private security or conduct information. Contributors may propose changes and request an explanation or reconsideration on the original discussion.

There is currently no designated backup maintainer or tested mechanism that guarantees restoration of repository, CI and release access within one week if the primary maintainer becomes unavailable. OpenSSF Silver access continuity and bus-factor requirements are therefore not met. Public Git history can be cloned and forked under MIT, but that does not itself restore privileged account access.

The maintainer confirmed familiarity with secure design principles and common Python/network vulnerabilities and their prevention. No bug, feature or vulnerability reports arrived outside GitHub in the preceding 12 months as confirmed in this project programme. The GitHub issue/advisory inventories were reviewed on 2026-10-16.
